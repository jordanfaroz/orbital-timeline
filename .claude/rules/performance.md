# Performance & Sustainability

## Performance is a Design Decision
- Slow interfaces feel broken — perceived performance matters as much as actual speed
- Use skeleton screens and optimistic UI to make apps feel instant
- Lazy load images and components below the fold
- Target **Core Web Vitals**: LCP < 2.5s, FID < 100ms, CLS < 0.1

## Sustainable & Ethical Design
- Energy-efficient interfaces reduce environmental impact — minimize unnecessary animations and heavy assets
- Use system fonts where possible to reduce font loading overhead
- Avoid dark patterns: infinite scroll without an exit, hidden unsubscribe flows, misleading CTAs
- Be transparent about data collection and algorithmic decision-making
