# Testing & Iteration

## Test Early, Test Often
- Don't wait for a polished prototype — test rough wireframes with real users
- Even 5 users in a usability test will surface 85% of major issues (Nielsen Norman)

## Testing Methods
| Method                    | Best For                              |
|---------------------------|---------------------------------------|
| Usability testing         | Finding friction in flows             |
| A/B testing               | Comparing design variants at scale    |
| Heatmaps / session replay | Understanding actual user behavior    |
| Surveys & feedback forms  | Gathering qualitative sentiment       |
| Accessibility audits      | Catching compliance gaps              |

## Data-Driven Decisions
- Combine quantitative (analytics, A/B tests) with qualitative (interviews, observations)
- Roll out changes incrementally and measure impact before full deployment
- Never rely on gut alone — but don't let data paralyze creativity either
