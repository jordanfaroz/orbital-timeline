# Tools & Resources

## Design
- **Figma** — industry standard for UI design and prototyping
- **UXPin** — code-backed prototyping with real component integration
- **Framer** — design + publish production-quality websites

## Component Libraries
- **shadcn/ui** — accessible, composable React components (used in this project)
- **MUI (Material UI)** — comprehensive React component library
- **Radix UI** — unstyled, accessible primitives for custom design systems

## Animation
- **Lottie (Iconscout)** — lightweight JSON animations for web and mobile
- **Framer Motion** — production-ready React animation library
- **GSAP** — advanced timeline-based web animations

## Accessibility
- **axe DevTools** — browser extension for automated accessibility testing
- **WAVE** — visual accessibility evaluation tool
- **Stark** — Figma plugin for contrast checking and accessibility annotations

## Testing
- **Hotjar** — heatmaps, session recordings, and feedback
- **Maze** — rapid usability testing with real users
- **Optimizely / VWO** — A/B and multivariate testing platforms
