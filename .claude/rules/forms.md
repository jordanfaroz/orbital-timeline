# Forms & Conversion

## Simplify Relentlessly
- Research shows most websites can cut form fields by **20–60%** without losing necessary data
- Only ask for information you'll actually use
- Use progressive disclosure: show additional fields only when relevant

## Validation & Feedback
- Use **inline validation** — show errors as users type, not only on submit
- Phrase errors constructively: "Enter a valid email address" not "Invalid input"
- Show a success state immediately after submission

## Field Best Practices
- Label fields above the input (not inside as placeholder — it disappears on focus)
- Group related fields visually
- Use appropriate input types (`email`, `tel`, `date`) to trigger the right mobile keyboard
- Auto-fill where possible; don't make users re-enter known data
