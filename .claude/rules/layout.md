# Layout & Structure

## Bento Grid Layouts
- Modular, card-based grid layouts (inspired by Apple's marketing style) are trending for dashboards and landing pages
- Divide content into digestible sections that can be scanned at a glance
- Works well for feature showcases, portfolio pages, and product highlights

## Visual Hierarchy with Grid
- Use an 8px grid system for consistent spacing
- Align elements to create visual rhythm and reduce decision fatigue
- Z-pattern and F-pattern scanning still holds for text-heavy pages; design accordingly

## Hero Sections
- Fragmented, asymmetric hero layouts are breaking away from the traditional centered-text + image template
- Include a single, clear CTA above the fold
- Avoid carousels/sliders — they perform poorly for engagement and accessibility

## Navigation
- Keep primary navigation items to **5–7 max**
- Mobile: consider bottom navigation bars over hamburger menus for core actions
- Sticky headers only when navigation is frequently needed — avoid for long-form reading
