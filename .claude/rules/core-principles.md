# Core Principles

## Clarity Over Cleverness
- Design should be immediately understandable — if a user has to think about how to use an element, it has failed
- Remove anything that doesn't serve the user's goal
- Prioritize function; let aesthetics enhance, not obscure

## Consistency Builds Trust
- Use the same button styles, spacing, colors, and patterns throughout the product
- Inconsistent interfaces are a leading cause of user frustration and abandonment (Baymard Institute)
- Define and enforce a shared component library across all teams

## User-Centered Design
- Every design decision should trace back to a real user need
- Design for the task, not the interface
- Continuously validate assumptions with real users — not just personas

## Reduce Cognitive Load
- Break complex tasks into smaller, digestible steps
- Use clear, plain language — avoid jargon
- Maintain predictable interaction patterns so users don't have to relearn
