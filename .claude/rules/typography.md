# Typography

## Hierarchy is Everything
- Use 2–3 font sizes max in a standard content block
- Establish a clear visual hierarchy: headline → subhead → body → caption
- Bold headlines help users scan; body copy should prioritize readability

## Bold & Expressive Typography
- 2025 sees a rise in **oversized, expressive headlines** — especially on landing pages (see: Dropbox, Nike, Drift)
- Experimental typefaces and variable fonts are gaining traction for brand differentiation
- Pair a display font with a neutral body font for contrast

## Practical Rules
- Line length: **45–75 characters** per line for optimal readability
- Line height: **1.5–1.7x** the font size for body text
- Avoid using more than 2 typeface families in a single interface
- Minimum body font size: **16px** on web
